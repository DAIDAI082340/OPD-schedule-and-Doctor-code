# 🏥 門診時段交叉查詢與醫師代碼查詢系統
> Outpatient Clinic Schedule Cross-Query & Doctor Code Assistant

專為臨床醫師、門診跟診護理師、轉診中心個管師、批價掛號櫃檯人員與行政同仁設計的門診排班交叉比對與代碼速查工具。支援跨科同時段看診醫師快速查詢、多位醫師每週門診全盤比對、以及科別與醫師代碼雙向檢索。

---

## 🚀 快速開始 (Quick Start)

本系統採 **Zero-dependency（純前端、零依賴、免安裝）** 架構設計：
1. 使用現代瀏覽器（Chrome, Edge, Safari, Firefox）直接雙擊開啟 [`門診時段交叉查詢與醫師代碼查詢系統.html`](file:///c:/Users/X4715G/Desktop/Antigravity%20專案/門診時段交叉查詢與醫師代碼查詢系統/門診時段交叉查詢與醫師代碼查詢系統.html) 或 [`index.html`](file:///c:/Users/X4715G/Desktop/Antigravity%20專案/門診時段交叉查詢與醫師代碼查詢系統/index.html)。
2. 系統提供兩大核心查詢功能：
   - **門診跨科比對 (同天同時段 / 不同時段)**：選擇基準醫師後，指定目標科別或醫師，即可秒級展開同天 **🟢 同天同時段（接續看診）** 與 **🟡 同天不同時段（跨上午/下午/夜診看診）** 的雙層對照結果。
   - **醫師/科別代碼速查 ＆ 門診時刻表**：下拉選擇科別展開醫師名冊，或直接輸入關鍵字（醫師姓名、代碼、科別）即時搜尋；**點擊任一醫師卡片即可彈出該醫師每週詳細門診時刻表**。

## 📋 核心功能特點 (Feature Highlights)

- [x] **跨科門診交叉查詢（同天同時段 ＆ 不同時段）**：
  - 依看診「星期」完整聚合，解決同天多時段拆散難讀問題。
  - 基準醫師時段自動提取（支援每週所有上午、下午、夜診時段）。
  - 目標支援「全科所有醫師」或「特定醫師」，快速查找同天看診名單。
  - **🟢 同天同時段**：高亮呈現完全重疊時段，適合病患同一個半天接續就醫。
  - **🟡 同天不同時段**：僅在目標有跨其他時段時呈現；若查無結果則自動隱藏色框，保持視覺清爽。
  - 即時顯示出診診間與特殊備註（如特診、限約診、隔週看診日期），且點擊醫師標籤均可彈出查看完整時刻表。
- [x] **科別與醫師代碼即時檢索**：
  - 支援 29 個科別代碼（如 AA、AB、AC、AD、01、03、06、07、08、12... 等）。
  - 88 位醫師主檔代碼速查（包含 `(0262) 陳詩典`、`(1212) 羅健寧` 等）。
  - 全域模糊搜尋（輸入醫師姓名、代碼或科別皆可秒級卡片化篩選）。
- [x] **✨ 點選醫師彈出門診時刻表 (Schedule Modal)**：
  - 點擊任何醫師卡片，立即浮層展開該醫師每週完整排班。
  - 標明看診星期、上下夜診、診間與特診限制備註，支援 Esc 鍵一鍵關閉。
- [x] **純前端零環境依賴**：完全本地運作，無後端伺服器或外部 CDN 依賴，醫院內網環境與離線狀態均可順暢操作。
